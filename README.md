# Walkers - 3D Spatial Sneaker Landing Page

A premium, interactive e-commerce landing page built with React, Vite, Tailwind CSS (v4), and Framer Motion. 

This project features a high-end 3D spatial aesthetic with glassmorphism, dynamic scrolling physics, and a fully functional light/dark mode toggle.

## ✨ Features
- **Spatial UI & Glassmorphism:** Immersive frosted glass panels and neon orbital glows.
- **Dynamic Physics:** Uses Framer Motion's `useSpring` and `useTransform` to track mouse movements and map them to 3D rotation physics.
- **Theme Toggling:** Seamless transition between a Deep Space Dark Mode and a crisp Monochrome Light Mode with Maroon accents.
- **Responsive Design:** Optimized for mobile, tablet, and desktop viewports.

## 🚀 Tech Stack
- **Framework:** React + Vite
- **Styling:** Tailwind CSS v4
- **Animation:** Framer Motion
- **Icons:** Lucide React
- **Typography:** Outfit

## 🛠️ Installation & Setup

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/walkers-landing-page.git
```
2. Navigate to the project directory:
```bash
cd walkers-landing-page
```
3. Install dependencies:
```bash
npm install
```
4. Start the development server:
```bash
npm run dev
```
